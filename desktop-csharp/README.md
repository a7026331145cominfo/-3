# الصقر ERP — تحويل واجهات React إلى C# / Windows Forms

هذه نسخة سطح مكتب مستقلة، أُنشئت بتحويل وحدات الواجهة الموجودة في \`web-client/src\` إلى عناصر ونوافذ C# ضمن \`desktop-csharp\`. أبقينا ملفات الويب الأصلية كما هي للمقارنة ولم نخلطها مع مشروع .NET.

## البناء والتشغيل

المتطلبات: Windows وVisual Studio 2022 أو .NET 8 SDK.

1. افتح \`desktop-csharp/AlSaqarERP.Desktop.csproj\`.
2. نفّذ Restore ثم Build.
3. شغّل التطبيق وافتح **الإعدادات → إعداد الاتصال بقاعدة البيانات**.
4. حدّد خادم SQL Server وقاعدة \`GTSdb2026\` واضغط **اختبار الاتصال**، ثم احفظ الإعدادات.

إعداد الخادم الافتراضي هو \`.\SQLEXPRESS\`، ويمكن تغييره. الإعدادات تحفظ في مجلد بيانات المستخدم المحلي. تُشفّر كلمة المرور المحفوظة بـ Windows DPAPI إذا كانت موجودة، وتُستخدم مصادقة Windows افتراضيًا.

## ملفات C# المحوّلة

- \`Program.cs\`: تشغيل تطبيق سطح المكتب ومعالجة أخطاء الواجهة.
- \`MainForm.cs\`: شريط الوحدات والتنقل بعلامات تبويب، وإدارة فتح الشاشات.
- \`ConnectionSettingsForm.cs\`: إعداد اتصال SQL Server واختباره.
- \`Models.cs\`: إعدادات المستخدم، وفهرس الشاشات والجداول والإجراءات.
- \`SqlServerService.cs\`: طبقة SQL Server، قراءة البيانات وبنية الجداول، تشغيل التقارير المسموح بها، وحفظ التعديلات الآمنة للبيانات الرئيسية.
- \`Controls.cs\`: رأس الشاشة، مستعرض الجداول، معلمات التقارير، اختيار سجل، ومعاينة الطباعة وتصدير CSV.
- \`Screens.cs\`: لوحة المؤشرات، المحاسبة، السندات، المبيعات، المشتريات، المخزون، المراكز، التقارير، الأمان، وفهرس الربط وبنية قاعدة البيانات.

## طريقة الربط والحدود المقصودة

- هذه نسخة C# مستقلة لسطح المكتب وليست مجرد تغيير امتداد ملفات TypeScript إلى \`.cs\`.
- المصدر React الأصلي يحفظ بياناته داخل \`localStorage\` وبيانات بداية تجريبية؛ لا يمكن نقل هذا السلوك إلى قاعدة SQL Server حقيقية من دون تعريف ربط كل عملية بالمخطط والإجراءات الفعلية.
- شاشات الفواتير والسندات هنا تعرض جداول قاعدة البيانات للقراءة فقط. لا يتم إنشاء/تعديل حركة مالية مباشرة في جدول الرأس أو التفاصيل لأن ترحيل الفاتورة قد يحتاج عدة إجراءات مترابطة. أُتيح الحفظ المباشر فقط لمجموعة محدودة من جداول البيانات الرئيسية.
- التقارير لا تُنفّذ إلا إذا كان اسم الإجراء ضمن قائمة السماح المحددة وكان موجودًا في قاعدة البيانات، وتطلب الواجهة قيم المعلمات وقت التنفيذ.
- لم نضمّن بيانات الدخول أو كلمات مرور قاعدة الإنتاج في المستودع.
