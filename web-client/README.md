# نظام الصقر المحاسبي — تطبيق سطح المكتب

هذا المشروع يغلّف واجهة الصقر الحالية في تطبيق Windows مستقل باستخدام Electron، ويُبنى منه ملف تثبيت `.exe`. المستخدم النهائي يفتح نافذة تطبيق من قائمة ابدأ أو اختصار سطح المكتب؛ ولا يحتاج إلى فتح المتصفح.

## تشغيل التطبيق أثناء التطوير

يتطلب Node.js 22 أو إصدارًا متوافقًا مع Vite.

```powershell
npm install
npm run desktop:dev
```

## بناء ملف التثبيت

على Windows:

```powershell
npm install
npm run lint
npm run desktop:dist
```

سيظهر ملف التثبيت داخل مجلد `release` باسم مشابه لـ `AlSaqarERP-Setup-1.0.0-x64.exe`.

كما يشغّل GitHub Actions عملية البناء على Windows ويرفع ملف التثبيت الناتج كـ Artifact باسم `AlSaqarERP-Windows-Installer`. يمكن تنزيله من صفحة Actions بعد اكتمال عملية البناء بنجاح.

## ملاحظات مهمة قبل الاستخدام الفعلي

- هذه حزمة سطح مكتب بواجهة Electron مبنية على مصدر React الحالي، وليست إعادة كتابة أصلية بـ C# / WPF.
- خدمة البيانات الموجودة حاليًا تستخدم `localStorage`، ولذلك البيانات محلية لملف مستخدم التطبيق على الجهاز؛ لا يعني بناء ملف EXE أن الاتصال بقاعدة SQL Server أصبح متوفرًا.
- لا تُضمّن بيانات دخول قاعدة البيانات أو مفاتيح سرية داخل الواجهة. يلزم مصدر خلفية موثوق وآمن قبل ربط قاعدة بيانات الإنتاج.
- لم يُتحقق من نجاح البناء الفعلي بعد؛ نتيجة البناء ستظهر في GitHub Actions.
